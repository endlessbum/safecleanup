# SafeCleanup v29.08.26
SafeCleanup — безопасная очистка и оптимизация системы Windows

# Возможности:
- Очистка TEMP и кешей браузеров (Chrome, Edge, Firefox, Opera, Brave, Vivaldi)
- Очистка корзины
- Очистка карантина
- Сканирование ESET Online Scanner (загрузка ~700 MB)
- Очистка кэша Windows Update
- Очистка DNS-кэша
- Редактирование белого списка для защиты важных папок
- Сводный отчёт по дисковому пространству
- Автоматическая ротация логов и управление конфигурацией
- HWID активация Windows/Office
- Оптимизация системы (лёгкая и средняя)
- Менеджер пользовательских скриптов
- Точки восстановления системы

# Установка
1. Скачайте репозиторий
2. Запустите SafeCleanup.ps1 от имени администратора
3. Следуйте инструкциям на экране

# Параметры запуска
- `-Quiet` — тихий режим (без запросов)
- `-AutoConfirm` — автоматически подтверждать все действия
- `-CustomPath <путь>` — использовать кастомный путь для хранения данных
- `-RunCleanup` — запустить очистку и выйти
- `-RunOptimize` — запустить оптимизацию и выйти
- `-Version` — показать версию

# Меню программы
```
0 — Очистить все (1, 2, 3, 6, 7, 8)
1 — Очистка системы (TEMP + кэш браузеров)
2 — Очистить корзину
3 — Очистить карантин (старые файлы)
4 — Онлайн-сканер ESET
5 — Редактировать белый список
6 — Очистка кэша Windows Update
7 — Очистка DNS-кэша
8 — Очистить старые логи
9 — Сброс (пересоздать конфигурацию)
10 — Изменить путь хранения данных
11 — Оптимизация
12 — HWID активация (Windows/Office)
13 — Выход
```

# Оптимизация
## Лёгкая оптимизация:
- Электропитание (максимальная производительность, отключение энергосбережения адаптеров)
- Обновления (отключение обновлений Windows)
- UAC (отключение уведомлений)
- Драйвера (отключение автообновления, поиск и удаление драйверов)
- C++ и DirectX (установка последних версий)
- Антивирус (отключение Защитника Windows)
- Мышь и клавиатура (отключение акселерации и залипания клавиш)
- Автозагрузка (отключение автозагрузки программ)
- Автономные карты (отключение и удаление)
- Microsoft Store (отключение автообновления приложений)
- Аппаратное ускорение браузеров (инструкции по отключению)
- Приложения (удаление мусорных приложений Windows)
- Визуальная часть (отключение прозрачности и визуальных эффектов)
- Телеметрия (отключение диагностических данных)
- Сбор данных (отключение планировщика задач)
- Диски (отключение индексации, очистка диска, удаление временных файлов)

## Средняя оптимизация:
- Электропитание (Bitsum Highest Performance)
- Службы (отключение ненужных служб Microsoft)
- Загрузка системы (отключение процессов автозагрузки)

# Настройка
- WhiteList хранится в `config/whitelist.txt`
- Конфигурация хранится в `config/settings.txt`
- Логи — в `C:\Users\Public\SafeCleanup\logs\`:
  - `main.log` — основной лог
  - `cleanup.log` — лог очистки
  - `virus_scan.log` — лог сканирования (ESET)
  - `error.log` — лог ошибок
  - `update_cache.log` — лог очистки кэша Windows Update
  - `dns_flush.log` — лог очистки DNS

# Структура папок
```
C:\Users\Public\SafeCleanup\
├── config\
│   ├── settings.txt    — конфигурация
│   └── whitelist.txt   — белый список защищённых путей
├── logs\               — логи программы
├── reports\            — отчёты
├── scripts\            — пользовательские скрипты
│   ├── SystemInfo.ps1       — информация о системе
│   ├── DiskCleanup.ps1     — дополнительная очистка диска
│   └── NetworkTools.ps1    — сетевые утилиты
└── temp\
    ├── av\             — временные файлы ESET
    └── quarantine\     — карантин
```
