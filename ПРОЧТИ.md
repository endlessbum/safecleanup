# Настройка Windows

Набор bat-скриптов для обслуживания и настройки Windows. Интерфейс на русском, запуск из командной строки.

| Файл | Назначение |
|------|------------|
| `Утилиты.bat` | Главное меню: система, очистка, приватность, службы, сеть, интерфейс |
| `Активатор.bat` | Активация Windows и Office (Microsoft Activation Scripts 3.12) |

Оба файла должны лежать в одной папке: пункт `[14] Активация Windows` в утилите запускает `Активатор.bat`.

## Требования

- Windows 10 / 11
- Запуск **от имени администратора**
- Интернет — для установки DirectX / VC++ / .NET и активации
- PowerShell (входит в Windows)

## Запуск

1. Скачайте оба `.bat` в одну папку.
2. ПКМ по `Утилиты.bat` → **Запуск от имени администратора**.
3. Введите номер пункта и нажмите Enter.

Если скрипт открыт без прав администратора, он сразу остановится с ошибкой.

## Возможности `Утилиты.bat`

### 1. Осмотр и компоненты

- Отчёт о системе: ОС, CPU, плата, ОЗУ, видео, диски, сеть, периферия
- Установка runtime: DirectX End-User, Visual C++ Redistributable (x86/x64), .NET Desktop Runtime 6 и 8
- Проверка уже установленных runtime

### 2. Очистка

Быстрая:

- корзина, Temp, кэш браузеров (Chrome, Edge, Firefox, Opera, Yandex, Brave, Vivaldi, Chromium)
- старые обновления Windows
- кэш проводника (иконки, эскизы, шрифты)
- DNS / Winsock

Глубокая:

- WinSxS (очистка компонентов и ResetBase)
- файл гибернации `hiberfil.sys`
- точки восстановления
- кэш Delivery Optimization

ResetBase необратим: после него нельзя удалять старые обновления по отдельности.

### 3. Приватность и ПО

Удаление предустановленных приложений (по одному или все сразу):

Камера, Центр разработки, Центр отзывов, Microsoft 365 Copilot, Bing, Clipchamp, Новости, Teams, To Do, Outlook, Power Automate, Быстрая помощь, Косынка, Звукозапись, Записки, Microsoft Store, Xbox, Edge.

Также:

- телеметрия и реклама
- уведомления и советы Windows
- фоновые UWP-приложения
- задачи планировщика (телеметрия / CEIP)
- Windows Copilot
- оптимизация доставки
- «тихий режим» — всё сразу

Удаление Store и Edge ломает установку приложений из магазина и часть системных функций. Делайте это осознанно.

### 4. Фон системы

- службы Windows: вкл/выкл по одной, все сразу, откат из резервной копии
- автозагрузка: список из реестра и папок Startup, отключение с резервом, восстановление

Перед массовым отключением служб скрипт сохраняет текущее состояние в `services_backup.txt`.

### 5. Производительность

- планы электропитания: высокая / максимальная / сбалансированный
- гибернация и быстрый запуск
- размер файла подкачки
- `bcdedit`: число ядер и объём ОЗУ
- лимиты питания CPU и Core Parking

Изменения через `bcdedit` действуют после перезагрузки.

### 6. Интерфейс и ввод

Проводник:

- открывать «Этот компьютер» вместо «Главная»
- скрыть Главную / Галерею / Сеть / OneDrive
- корзина в навигации и на рабочем столе
- компактный вид, недавние файлы, классическое контекстное меню
- расширения файлов, скрытые файлы, полный путь, флажки

Плюс визуальные эффекты, задержка меню, сжатие обоев JPEG, раздел «Рекомендуем» в Пуске, очистка панели задач.

Ввод и игры:

- ускорение мыши
- залипание клавиш
- фоновый запуск Edge
- Game Bar / DVR / Game Mode

### 7. Обслуживание

- отключение индексации содержимого на выбранных дисках
- проверка целостности: DISM RestoreHealth + SFC
- UAC: ослабить или вернуть стандартный уровень
- запуск активатора

Ослабление UAC отключает запрос согласия для администраторов (`ConsentPromptBehaviorAdmin = 0`). Это удобнее, но снижает защиту.

## Активатор

`Активатор.bat` — локализованная сборка [Microsoft Activation Scripts](https://massgrave.dev) 3.12.

Методы:

| Пункт | Метод | Что активирует |
|-------|--------|----------------|
| 1 | HWID | Windows (цифровая лицензия) |
| 2 | Ohook | Office |
| 3 | TSforge | Windows / Office / ESU |
| 4 | Online KMS | Windows / Office |

Дополнительно: статус активации, смена редакции Windows и Office, устранение неполадок, извлечение `$OEM$`, скачивание оригинальных образов.

## Состав репозитория

```
.
├── Утилиты.bat      главная утилита
├── Активатор.bat    активация Windows / Office
└── ПРОЧТИ.md
```

При работе скрипты могут создать рядом:

- `services_backup.txt` — резерв служб
- `startup_backup\` — отключённые элементы автозагрузки

Временные файлы установщиков кладутся в `%TEMP%\DX_VC_Install`.

## Важно

- Скрипты меняют реестр, службы, BCD и политики Windows. Перед массовыми правками сделайте точку восстановления.
- Часть пунктов (ResetBase, удаление Store/Edge, ослабление UAC, `bcdedit`) трудно откатить «одной кнопкой».
- Антивирусы часто ругаются на bat-файлы, которые правят лицензирование и службы. Это ожидаемо для такого класса утилит.
- Используйте на своей машине и на свой страх и риск.

## Лицензия

Скрипты предоставляются «как есть», без гарантий. `Активатор.bat` основан на Microsoft Activation Scripts (MAS).
